# UniMod v0.55 Test 11

## mod.io (read-only)
1. On mod.io go to Account → Access. Generate a fresh API key if an earlier key was visible in a screenshot.
2. Copy only the digits from the documented `https://u-{your-user-id}.modapi.io/v1` **User API path** into **mod.io User ID**.
3. Pick mod.io, enter the **Game ID** into Community / Game ID, and enter the private key in UniMod's masked key field. Never send it to support chat.
4. Select **Verify mod.io game ID…** and confirm the returned game title.
5. Search official catalogue. Matching results are suggestions, not automatic proof of an installed DLL.

This is read-only: no mod.io account changes, subscription writes or automatic mod installations. Supported providers otherwise unchanged.
