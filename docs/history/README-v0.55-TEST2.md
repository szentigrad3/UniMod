# UniMod v0.55 Test 2

Test 2 fixes the misleading **Identify mod sources automatically** button when a non-SMAPI game such as Graveyard Keeper is selected. Choose Graveyard Keeper, open **Updates Available**, then select **Resolve sources for this game…** to review BepInEx source matching. No SMAPI lookup or automatic installation occurs. On Stardew Valley, the button still uses SMAPI automatic source lookup.

**Note:** identifying unknown Graveyard Keeper mod sources still requires confirmed metadata or manually assigned trusted pages. The update page will continue to display **Source needed** until a source is verified. Nexus OAuth is still approval-gated.
