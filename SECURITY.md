# Security policy

## Supported versions

UniMod is currently a development preview (`0.55.0-test12`) and has no guaranteed support or patch window. No security audit has been completed.

## Reporting vulnerabilities

**Do not disclose exploitable details or credentials in public GitHub Issues.** Use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise contact the maintainer privately using the repository's GitHub profile and request a secure reporting channel; do not include a working exploit or secret in the first public message.

Security-sensitive components include provider URL allowlists, API credentials, authentication redirects, archive validation, profile detection, install backups and rollback.

If an API token has appeared in a screenshot or public issue, revoke it with the provider before doing anything else.
